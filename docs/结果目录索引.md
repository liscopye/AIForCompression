## 3. 保留的专项与历史证据

以下结果不进入 objective-v1 主排名，但保留有解释或复现价值：

| 类别 | 典型目录 | 用途 |
|---|---|---|
| matched validation | `unified_results/matched_validation_20260721/` | objective-v1 前的统一输入验证 |
| ERA5 早期 cadence/稳定性 | `unified_results/caesar_era5_*` | 解释训练数据 cadence、normalization 与 loss 选择 |
| CAESAR 消融 | `unified_results/no_pca_lpips_fill/`、`unified_results/experiments/` | PCA/no-PCA、图像 codec+PCA 等消融 |
| 外部 codec 结果 | `unified_results/*_external_models_*` | cuSZ/nvJPEG2000 等早期专项结果 |
| GraphComp | `unified_results/graphcomp_*` | 外部方法复现；不进入正式排名 |
| 2026-06-11 旧归档 | `unified_results_archive_20260611_035153/` | 历史追溯，不是权威结果 |

旧 `unified_results/final/`、`raw/`、`merged/`、正式聚合前的 shards，以及未被交接文档引用的 smoke/debug/probe 已于 2026-08-11 清理。保留目录主要是 JSON、图、小模型或日志，用作最终交付或仍有价值的历史证据。

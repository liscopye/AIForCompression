## 4. 暂不删除

在完成依赖反查和去重前，不删除：

- 整个 `checkpoints/caesar/`；其中包含原始、Turb-Rot 和 Lysozyme tuning 权重；
- 整个 `wandb/`；先将 run ID 与 ERA5 最终/失败结论对齐；
- `/workspace/Data/`；这是外部数据集，不是实验垃圾；
- `/workspace/AIForCompression_graphcomp_train` 与 `/workspace/AIForCompression_nvjpeg`；它们是独立历史工作副本，需单独交接或归档；
- 工作树中的任何未跟踪脚本、测试、协议和文档。
